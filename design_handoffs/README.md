# Claude Design handoff archive

Claude Design exports live here together so the current handoff and the exports it supersedes stay
available in chronological context.

| Order | Directory | Status | Coverage |
| --- | --- | --- | --- |
| Older | `design_handoff_drinksmart_depreciated/` | Historical only | Original redesign through `1o` |
| Newest | `design_handoff_drinksmart/` | **Active and authoritative** | Original redesign plus Wave 4 `4a`–`4o` |

Only the active, unsuffixed directory is a source of truth for implementation or visual checking.
Directories marked `depreciated` preserve earlier exports for comparison and must not be used to
settle current values. Inside the active bundle, `README.md` is the prose specification,
`screens/*.html` is authoritative for literal values and copy, and `screens/*.png` is authoritative
for appearance.

Windows `:Zone.Identifier` metadata is export noise and must be removed before a handoff is tracked.
