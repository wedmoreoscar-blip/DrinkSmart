## Clauses

**1. Replace the stats card with the 2 × 2 figure grid and the `Method` row.**
Screen padding `20px 20px 0`, 10px between cards, cards `#232532` radius 14 padding 16.

The body card holds a 2-column grid of 60px cells, gap 10, each cell `#1c1e2c` radius 12 padding
`8px 14px`: a 13px/0.09em uppercase `#75798c` label above a 28px/500 tabular value with its unit at
19px `#b2b6ca`. The four cells are **weight, height, age, sex** — read from `useUserMetrics()`'s
`savedMetrics` (`UserMetricsData`, whose fields are the strings `weight`, `weightUnit`, `heightCm`,
`heightFt`, `heightIn`, `heightUnit`, `age`, `sex`, `metricType`, `bodyFat`).

Below the grid, one full-width 56px row: label `Method` with its value (`BMI` or `FFMI`, from
`metricType`) and an 18px `#75798c` chevron.

**When `metricType === "ffmi"` the grid gains a fifth 60px cell, `Body fat`, with no tag** — because
on that path it genuinely is in the arithmetic. On the BMI path there is **no body-fat row, no
estimate, and no mention of body fat anywhere on the screen.** Do not add an estimated default.

Inside the same card, at 17px `#b2b6ca`, the literal line: `Editing these re-runs tonight's timeline.`

Tapping a cell or the `Method` row must open an editing affordance that writes through
`saveMetrics(metrics)` from `useUserMetrics()`. Build that editor as a `1m` sheet
(`src/components/ui/sheet.tsx`) containing the existing `Input` and `Select` primitives — **do not
import `StatsForm`**, and do not use the `4o` keypad (another agent is building it concurrently and
it will not exist in your worktree).

**2. Make the two preference rows sheet-backed, and move the reminder switches into one.**
Replace the current inline `PreferencesPicker` card with a card holding exactly two 56px rows
separated by a 1px `#292b31` divider, each with an 18px `#75798c` chevron:

- `Taste`, whose value is the current word-stop word (for example `dry-ish`);
- `Reminders`, whose value is a short summary such as `drinks only`.

Each row opens a `1m` sheet. Three switches sitting on the tab itself is what made the screen read
as Settings, so any reminder switches belong inside the `Reminders` sheet, never on the tab.

**3. Render the Account card third, as a fact rather than a nag.**
Card label `Account`; a 22px line reading `Anonymous — this phone only` when the session is
anonymous (`isAnonymousSession(session)`, already imported in the file); 17px body; then **the
screen's one 64px primary**, `Add an email`, which navigates to `/auth` exactly as the current
button does. For a permanent account, show the email and the existing sign-out control instead.

It is never a banner, never at the top, and **there must be no dismissable upgrade prompt anywhere
else on the screen.**

**4. Put the admin group below the fold, after a fading rule, and render it only for admins.**
A 13px uppercase `Admin` heading with an `admin only` badge, then 56px rows (the existing
`Manage feedback` navigation to `/admin/feedback`). It renders **only when `isAdmin` is true** from
`useUserRole()`. For everyone else it is **absent** — never disabled, never a locked row, never a
placeholder. Nothing above it may shift, so that no one can tell something is missing.

The fading rule above it is the design's 1px horizontal gradient, matching the one already used in
`src/components/onboarding/PreferencesPicker.tsx` (`WordStopRail`, ~line 54):
`linear-gradient(to right,transparent,rgba(233,233,237,.16) 30px,rgba(233,233,237,.16) calc(100% - 30px),transparent)`.
